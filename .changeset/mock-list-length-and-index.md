Lists generated by the mock store can set a length with `defaultListLength`, and `MockList` now passes each item's index to its mock function.

Without an explicit list mock the store always produced two items. `addMocksToSchema({ schema, defaultListLength: 0 })` (or `createMockStore`) now controls that length. `new MockList(n, (index) => ...)` receives `index` so items can vary by position.
